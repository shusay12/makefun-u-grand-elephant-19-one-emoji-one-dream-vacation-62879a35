# One Emoji, One Dream Vacation

An entry for make.fun's **u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35** bounty: send exactly one emoji for your dream vacation, and a judge picks the most evocative.

The entry is a single emoji — 🏝️ (U+1F3DD DESERT ISLAND + U+FE0F) — a palm island in a turquoise sea: a wordless postcard of escaping to a tiny island of your own, far from everything.

## How it works

`main.py` (Python 3.13 standard library only, no network) scores six candidate emojis against the judge's five criteria — plainly a dream vacation, vivid at a glance, personal and specific, a spark of wit, instantly readable — picks the best, and writes it, with no trailing newline, to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Layout

- `main.py` — the entry program
- `run1/entry.txt`, `run2/entry.txt` — the two local runs (byte-identical)
